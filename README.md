# PRP Steganography LSB Technique

Dit project gaat over het verbergen van berichten in afbeeldingen met de LSB-techniek (Least Significant Bit).

## Hoe werkt het?

De LSB-techniek verbergt geheime data in de kleinste bits van pixels in een afbeelding. Omdat deze bits vrijwel onzichtbaar zijn voor het menselijk oog, kan je een bericht verstoppen zonder dat iemand het ziet.

## Wat zit in dit project?

- Code om berichten in afbeeldingen in te voegen
- Code om verborgen berichten weer uit afbeeldingen te halen
- Voorbeelden van hoe je het gebruikt

## Hoe gebruik je het?

1. Kies een afbeelding
2. Voer je geheime bericht in
3. De code verbergt het bericht in de afbeelding
4. Delen en later weer uitlezen met de juiste code

Dat is het!
